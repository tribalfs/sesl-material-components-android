open class FloatingGroupLayout @JvmOverloads constructor(context: Context, attrs: AttributeSet? = null, defStyleAttr: Int = 0) : FrameLayout, CoordinatorLayout.AttachedBehavior, BlurSupportable, MaterialLogTag

Base layout container for Samsung OneUI floating components.

Provides smooth show/hide transitions, scroll integration with SeslScrollable views, background projection rendering, and blur support.
