FloatingAware

interface FloatingAware

Interface implemented by components that participate in a floating action container, exposing reference views and bounding insets to position projection backgrounds and reacting to floating background transition events.

Implementations can be supplied to a floating container layout (such as FloatingGroupLayout or FloatingToolbarLayout) via floatingAware to control how projection backgrounds align with reference views, as well as to receive callbacks during transition animations and configuration changes.

Default implementations like FloatingGroupAware and FloatingToolbarAware are provided for standard container and toolbar integration.
