FloatingToolbarLayout

open class FloatingToolbarLayout @JvmOverloads constructor(context: Context, attrs: AttributeSet? = null, defStyleAttr: Int = 0) : FloatingTopLayout

Floating toolbar layout container integrating a Toolbar and optional action mode bar.

Manages item projection backgrounds, title alpha transitions synchronized with AppBarLayout states, and selection view animations.
