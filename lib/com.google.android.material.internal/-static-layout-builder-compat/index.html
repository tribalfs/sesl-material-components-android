StaticLayoutBuilderCompat

@RestrictTo(value = Scope.LIBRARY_GROUP)
class StaticLayoutBuilderCompat

Class to create StaticLayout using StaticLayout.Builder on API23+ and a hidden StaticLayout constructor before that.

Usage: 


StaticLayout staticLayout =
  StaticLayoutBuilderCompat.obtain("Lorem Ipsum", new TextPaint(), 100)
    .setAlignment(Alignment.ALIGN_NORMAL)
    .build();
