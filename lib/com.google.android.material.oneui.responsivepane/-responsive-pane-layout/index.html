ResponsivePaneLayout

class ResponsivePaneLayout @JvmOverloads constructor(context: Context, attrs: AttributeSet? = null, defStyleAttr: Int = 0) : ConstraintLayout, Openable, ResponsivePaneTag

An adaptive Samsung One UI container layout extending ConstraintLayout that manages side navigation drawers and content panes, supporting responsive pane states (OPENED, CLOSED) across tablet, foldable, and desktop screens.

Integrates with One UI elevation concepts, predictive back handling via [OnBackInvokedDispatcher], and drag gestures.
